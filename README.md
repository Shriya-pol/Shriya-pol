## Featured project · First Step

First Step is a product concept that helps college students start assignments that feel overwhelming.

I interviewed three students about assignments they put off and tasks they found easier to start. A pattern emerged. Getting started felt easier when the next action was clear. That shaped the concept. First Step offers examples of small actions, so students have something concrete to choose from when they’re stuck.

My next research question is whether showing examples helps students start sooner and how perfectionism affects which first steps feel manageable.
